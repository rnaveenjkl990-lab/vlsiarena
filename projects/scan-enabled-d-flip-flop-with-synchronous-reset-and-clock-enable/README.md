## Project Overview

A fundamental synchronous storage element with integrated Design-for-Test (DFT) scan capability, clock gating control, and synchronous reset. In digital IC design, scan-enabled flip-flops allow automated test pattern generation (ATPG) to shift serial test vectors through internal registers during manufacturing test while functioning as standard enabled flip-flops during normal operation. This module provides deterministic multiplexing between functional and scan inputs with well-defined control priority.

## Full Task Specification

Your task: implement the scan_dff design described in this specification.
Write the complete synthesizable SystemVerilog module with the interface below.
  - clk: input, width 1
  - rst_n: input, width 1
  - d: input, width 1
  - en: input, width 1
  - scan_en: input, width 1
  - scan_in: input, width 1
  - q: output, width 1
Behavior to implement: When rst_n is 0 on the rising edge of clk, the output q must update to 0 on that clock edge, regardless of scan_en, scan_in, en, and d.; When rst_n is 1 and scan_en is 1 on the rising edge of clk, the output q must capture scan_in on that clock edge, regardless of en and d.; When rst_n is 1, scan_en is 0, and en is 1 on the rising edge of clk, the output q must capture d on that clock edge.; When rst_n is 1, scan_en is 0, and en is 0 on the rising edge of clk, the output q must retain its current value..
Corner cases your design must handle: Simultaneous rst_n=0 and scan_en=1: reset must take priority and drive q to 0.; Simultaneous scan_en=1 and en=1 with differing d and scan_in: scan_in must be captured into q, ignoring d.; Simultaneous scan_en=1 and en=0: scan_in must still be captured into q despite en being low.; Continuous hold across multiple cycles: with rst_n=1, scan_en=0, en=0, q must remain stable while d and scan_in toggle..
