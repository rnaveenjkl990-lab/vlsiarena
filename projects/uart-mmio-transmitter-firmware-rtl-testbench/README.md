8N1 serial: idle high, one low start bit, eight LSB-first data bits and one high stop bit.
Every UART bit lasts exactly 4 rising-edge clock periods.
STATUS bit 0 equals !busy. All other STATUS bits are zero.
A TXDATA write at offset 0x04 is accepted only when busy is 0.
Each mmio_read32/mmio_write32 operation is translated into real RTL bus activity; no DUT state is overwritten directly.
firmware_send(bytes,count,poll_limit) returns 0 after all requested frames complete and -1 for invalid input or exhausted polling.

Register map:
0x00000000: STATUS [0:0] TX_READY none
0x00000004: TXDATA [7:0] DATA Writing bits[7:0] while TX_READY=1 begins a frame; writes while busy are ignored.
